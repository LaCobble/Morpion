## [1.0.0] - 2022-03-17

First version, as delivered for the school assignment.

### Added

- Console Tic-Tac-Toe on a 3 x 3 board: the player enters coordinates, the computer answers.
- Computer moves chosen with the Minimax algorithm.
- Input validation with dedicated exceptions (`ApplicationException`, `IntException`).
